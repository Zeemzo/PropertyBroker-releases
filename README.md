# Property Broker: downloads

Property Broker is a personal manager for property brokers. It keeps listings with automatic codes, owners, buyers and lawyers, deals, reminders and a full history. Everything is stored on your own devices, and devices sync over Wi-Fi or with a sync file.

**[⬇ Download the latest version](https://github.com/Zeemzo/PropertyBroker-releases/releases/latest)**

| Device | File |
|---|---|
| Windows | `…-windows-setup.exe` (installer) or `…-windows-portable.exe` (no install) |
| Mac | `…-mac-arm64.dmg` (Apple Silicon) or `…-mac-x64.dmg` (Intel) |
| Android | `…-android.apk` |

Once installed (version 1.3.0 or later), the app finds new versions here by itself and offers to update. Your data stays on your devices when you update.

This repository holds only the release files. The source code is private.
